One line, under 200 characters, about crypto and trading life — entered in the
[Laugh Track: The Crypto Trading Joke Contest](https://make.fun/competitions/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a)
on make.fun.

## The joke

> Leverage 100x: because losing my money slowly felt disrespectful to my time.

It won the candidate tournament (specificity 5, surprise 5, freshness 4) as the
sharpest of eight drafts: 100x leverage is a recognisable trading detail, the
setup is one breath, and the punchline turns the loss into a joke about
impatience instead of a complaint about the market.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to
`/output/entry.txt` as UTF-8 text, exactly one line, no trailing newline.

```sh
python3 main.py            # write the entry
python3 main.py --check    # write it and verify the round-trip
python3 main.py --self-test  # verify against a temp file
```
